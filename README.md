NeuraBot - Personalized AI Chatbot
NeuraBot is a personalized conversational AI chatbot built using the AgentX AI platform. It delivers ChatGPT-like, context-aware responses across multiple domains, including coding, education, reasoning, and image understanding, with fast and clear medium-length replies.
 🤖 NeuraBot 


---

 ✨ Features
- ChatGPT / Gemini–like conversational behavior
- Context-aware responses within a session
- Fast and medium-length replies
- Programming assistance with formatted code output
- Educational explanations and reasoning support
- Image understanding and analysis
- Tool-based assistance (e.g., YouTube content search)
