# Conversation Starters – NeuraBot

These starters help users quickly understand what NeuraBot can do and provide an easy entry point into the conversation.

---

## General
- Ask me anything
- What can you help me with?
- Explain a concept in simple terms

---

## Programming & Technology
- Help me debug this code
- Explain this code step by step
- Write a program for this problem

---

## Learning & Education
- Explain this topic like I’m a beginner
- Summarize this topic for quick revision
- Give real-world examples for this concept

---

## Reasoning & Problem Solving
- Solve this problem step by step
- Compare two concepts clearly
- Explain the pros and cons

---

## Image Understanding
- What’s happening in this image?
- Extract text from this image
- Identify important elements in this image

---

## Tools & Exploration
- Show me YouTube tutorials on this topic
- Find learning resources for this subject
